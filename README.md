# Programadores para la Paz: Capacitación en Democracia y Tecnología
 
Este repositorio contiene las actividades desarrolladas durante el curso **Programadores para la Paz: Capacitación en Democracia y Tecnología**.
 
## Descripción
 
El repositorio está organizado por semanas e incluye ejercicios sobre:
 
- Ciudadanía digital
- Git y GitHub
- Node.js
- Express
- APIs
- Servidores
- Seguridad
- Metodologías ágiles
- Bases de datos
- Autenticación
- Automatización
## Entorno de trabajo
 
Las actividades fueron realizadas en **GitHub Codespaces**.
 
## Objetivo
 
Este trabajo está enfocado en crear soluciones tecnológicas sencillas, seguras y útiles para fortalecer la participación ciudadana y la organización comunitaria.
